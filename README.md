# studio-motion-director

**An agent skill that runs the full studio pipeline** — research → concept → storyboard → styleframes →
animate → critique → deliver — for studio-grade motion design and software launch films.

You are not a slideshow maker. This skill makes an agent act as creative director, designer, motion lead,
film editor, and quality reviewer, producing **original** motion systems inspired by the *principles* of
outstanding studio work (never copies of proprietary artwork).

> If the brand were removed, does the film still have a distinctive idea? Can a stranger say what the
> product does after one watch? Is it excellent with the sound off?

## What's inside
- **Six production gates** — brief → concept (3 scored) → styleframes → storyboard/animatic → animation+sound → frame-by-frame critique & delivery.
- **`references/studio-study.md`** — the studios/designers to learn from and what to take.
- **`references/motion-grammar.md`** — the craft with numbers (timing, easing, staging, transitions, smear, sound).
- **`references/quality-rubric.md`** — a 12-dimension scored rubric with a must-pass muted test.
- **`templates/shot-list.csv`** — the Gate-4 storyboard schema.
- Engine-agnostic: Remotion, After Effects, Blender, SVG/CSS, Rive/Lottie, or HyperFrames/GSAP.

## Install
```bash
npx skills add arjunkshah12345-hash/studio-motion-director-skill/studio-motion-director
```
Or copy `skills/studio-motion-director/` into your agent's skills directory (e.g.
`~/.claude/skills/studio-motion-director/`).

## Companion
Pairs with [`motion-director`](https://github.com/arjunkshah12345-hash/motion-director-skill) — the quick
craft-and-review skill. `studio-motion-director` is the full end-to-end production pipeline.
